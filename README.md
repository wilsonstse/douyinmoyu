# 抖音后台遥控

Windows 上的独立小窗，提供“上一个”“下一个”“暂停/继续”和“下载当前视频”。Chrome 和抖音标签页可以留在后台；电脑需要保持开机，Chrome 也需要运行。下载文件保存到 `D:\下载`。

## 安装

1. 在 Chrome 地址栏打开 `chrome://extensions`，打开右上角“开发者模式”。
2. 点“加载已解压的扩展程序”，选择此目录下的 `extension` 文件夹。
3. 刷新已经打开的抖音页面（`www.douyin.com`）。
4. 双击 `start.bat` 启动控制小窗。命令窗口会同时保持打开，以便显示运行错误；关闭控制小窗即可结束程序。

如果扩展已经安装过，修改后的版本需要在 `chrome://extensions` 中点扩展卡片上的“重新加载”，然后刷新抖音页面。启动控制窗后可能需要几秒建立连接。

Chrome 会显示扩展正在调试标签页的提示，这是后台发送上下键所需的 Chrome 接口。关闭小窗后本地服务停止；关闭扩展即可完全停止遥控。

如果启动失败，命令窗口会显示错误并暂停。需要本机安装 Python 3，并确保端口 `17853` 没有被占用。首次运行时，Windows 防火墙如有提示，只需允许本机使用，无需开放公共网络。

## 说明

扩展只连接本机 `127.0.0.1`，控制 `www.douyin.com` 标签页。抖音页面改版后，切换键的行为可能变化。若开了多个抖音标签页，请只保留一个需要控制的页面。

下载功能从抖音页面已加载的视频列表中按当前视频 ID 查找对应的媒体地址，再由 Chrome 下载，完成后自动移到 `D:\下载`。下载过程中显示百分比；如果服务器没有提供总大小，则显示已下载大小。它不再访问被 403 拒绝的视频详情接口，也不读取浏览器 Cookie。首次使用时如提示“尚未匹配当前视频”，请切换到下一个视频，播放几秒后再点下载。不会再用其他视频的媒体地址代替当前视频。Chrome 会显示扩展正在调试标签页的提示；这是捕获视频列表所需的接口。受视频权限或抖音改版影响，个别视频仍可能无法下载。
